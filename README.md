# The page!

For about two years I wanted to make my own page to showcase my drawings and other creations. I found problems and excuses to avoid making it. And, on one evening I just got to it with anger and passion. I had the page done mostly in one cycle. For this I waited two years.

I had to deal with various workarounds not being able to deal with requests. But it is just fine - this is what I can afford being a student, and, moreover, I got the limitations used for my advantage. 

The code, however, may be unethical at some moments. Still, it does not bother me to make a **push** with each image upload. I am comfortable with that.



## Notes

Every functional part of this was written in HTML and JavaScript in about four cycles.



## Structure

The resources are located in "docs" directory and its subdirectories.



### pages
This directory stores main pages, including gallery, library, legend and ego(labelled as "creator"). It also has a forking page for workshop, which is divided into contraptions and digital.

All the titles mentioned here correspond to the files.



### bits
Parts of the pages. This includes the header as well as text for all of the gallery entries.

### css
 - common.css - common for all pages, sets basic classes and options.
 - header.css - style for the header.
 - ego.css, gallery.css, legend.css - page-specific styles.
 - entries.css - common style for library, legend, workshop, contraptions, digital and ego.
 - neonight.css - colorscheme.

### js
 - common.js - a script for including the header.
 - ego.js - hardcode over entries.js
 - entries.js - script for managing the miniature gallery buttons in workshop-based pages.
 - gallery.js - responsible for loading text, images, responding to buttons and switching background.

### images
A directory to store all of the images used. Also the easiest way to access my drawings and photographs in best quality.

### other
A directory for any other type of files used, such as book PDFs.
